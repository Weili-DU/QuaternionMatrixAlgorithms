# 论文笔记 - 四元数矩阵同时分解算法

## 论文信息

**标题**: Simultaneous Decomposition of Some Quaternion Matrices for Image Watermarking  
**领域**: 四元数矩阵分解 / 图像隐写  
**关键词**: 四元数矩阵, 同时分解, 图像水印, DWT变换

## 算法概述

本算法提出了一种基于四元数矩阵同时分解的彩色图像隐写方法。通过将多个四元数矩阵同时分解，实现在彩色图像的HH子带中嵌入隐秘信息。

### 核心思想

1. **四元数表示**: 使用四元数表示彩色图像的RGB通道
2. **同时分解**: 对多个四元数矩阵进行同时分解
3. **信息嵌入**: 在分解后的特征矩阵中嵌入隐秘信息
4. **图像重构**: 使用逆变换重构嵌入后的图像

### 数学基础

**分解公式**:
```
A_i = M_{i-1} * S_i * M_i^{-1}
```

**嵌入公式**:
```
S_i' = S_i + α * W
```
